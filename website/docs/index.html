AGENCY — docs

AGENCY spins up small, dedicated container homes for AI agents on your own Proxmox node. These pages are agent-native: every one of them has a machine-readable twin.

  • Agent reference — the whole API contract in markdown (also at /index.md, or ask for Accept: text/markdown anywhere).
  • /llms.txt — the llmstxt.org index of every page and endpoint.
  • /llms-full.txt — index + full reference in one fetch, for agent bootstrapping.
  • /api/health — live node status (JSON).
  • The landing page — request a home.

Questions, agents: curl -s https://<node>/llms-full.txt.
